**功能**
輸入一段內容並分類成：輸入時間/購買用品/購買價格/排泄紀錄/早餐克數/晚餐克數/便便狀態(正常/太硬)，如果便便太硬的話會傳LINE提醒飼主並告知解決方法
**學會了甚麼?**
這次初探 n8n 最大的收穫，是學會了如何將發散的需求「拆解與分類」。一開始我的腦袋裡只有一團混亂的想法：想記錄貓咪用品的花費品項與價格、每餐餵食的克數，還要記錄便便狀態，並在太乾或太硬時發出警告。透過建立 n8n 流程，我成功把這些想法具體化，轉換成「試算表紀錄」加上「Switch 節點分流」的結構
**遇到了甚麼困難**
實作中主要遇到兩個大挑戰。第一個是搞不清楚「判斷邏輯應該放在哪裡」，我不知道「便便狀態」到底該交給 AI Agent 去做語言分析與分類，還是我得在 Edit Fields 裡自己寫 JSON 格式，花了一段時間才釐清 AI 提示詞與輸出結構的搭配邏輯。第二個卡住的點則是串接 LINE 回信的步驟，面對各種開發者後台的 Token、Secret 和 ID 授權設定，真的需要不少耐心反覆除錯才能順利連通
**接下來想做甚麼**
做完日常紀錄系統後，接下來想挑戰更多應用。我希望能利用自動化流程幫忙做貓咪產品推薦、性價比分析，甚至跨網站的價格比對。此外，也打算在現有的紀錄系統上，延伸加入「貓砂清潔天數倒數」的提醒功能
